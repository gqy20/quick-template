quick-template

把项目约定变成可验证的生成结果

一套 CLI 组合语言模板与共享工程契约，生成后即可安装依赖、运行检查， 并由开发者或编码 Agent 接管。

从 GitHub 安装

uv tool install git+https://github.com/gqy20/quick-template
立即生成 阅读文档
  • MIT License
  • Python 3.11+
  • GitHub Actions 验证

Verified baseline 六种语言 / API 组合使用同一套门禁。

生成结果的证据

不是文件堆，而是可运行的项目

生成器、模板资源、语言工具链和 wheel 安装路径都进入持续集成， 文档只描述已经通过验证的能力。

  • 六种组合三种语言分别验证 API 开启与关闭
  • 条件完整关闭能力后不残留文件、import 或 workflow
  • wheel 可用在新环境安装后仍能读取全部模板资源
  • 原生门禁每种语言运行自己的 lint、类型、测试与构建
生成与验证 CI path 
$ quick-template --language python \
    --output-dir ./my-python-app

Project generated: my-python-app

$ cd my-python-app
$ make all

check      passed
typecheck  passed
test       passed

示例展示标准验证路径；实际命令由生成项目中的 Makefile 定义。

工程基线即治理

规则随代码进入仓库

约定不是外部 Wiki。它们与生成项目一起版本化，并由 Agent 和开发者共同遵守。

AGENTS.md

面向开发者和编码 Agent 的执行契约

定义事实源、授权边界、架构不变量、验证阶梯与完成标准。

先确定交付物、范围、非目标、验证和停止条件。
DESIGN.md

面向产品界面的稳定设计契约

固定语义 Token、信息顺序、响应式、无障碍和 Design QA 门禁。

上下文、当前状态、依据、可执行动作、详细历史。
  • 仓库内版本化
  • 人和 Agent 共用
  • 变更可审计
  • 规则可验证

Python 可选能力

两种原生 Agent Runtime，共享一套工程协议

Prompt、结构化输出和审计日志保持中立；状态、工具和控制流遵循各自框架的原生语义。

Runtime A

Claude Agent SDK

  • 原生 Agent loop 与消息类型
  • MCP、Skills 和权限配置
  • 会话隔离与可选恢复
  • 适合 Claude 原生工具生态

Shared contract

共享协议

Prompt YAML
版本与变量契约
Pydantic output
跨 Runtime 结构化结果
Audit logs
脱敏 JSONL 事件

Runtime B

LangGraph

  • 显式 StateGraph 与条件路由
  • 原生 ToolNode 工具循环
  • checkpoint 与 interrupt / resume
  • MCP 工具显式授权

从基线出发，立即生成并验证

三步得到一个可以继续开发的真实仓库。

  1. 1

    安装

    从 GitHub 安装 CLI

    uv tool install git+https://github.com/gqy20/quick-template
  2. 2

    生成

    选择语言和输出目录

    quick-template --language python --output-dir ./my-app
  3. 3

    验证

    运行生成项目的统一门禁

    cd my-app && make all
查看完整用法
