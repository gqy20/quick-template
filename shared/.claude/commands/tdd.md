# TDD

1. 从当前请求选一个可观察的行为，用项目已有测试框架写一个断言。运行该用例，确认失败原因是缺少预期行为。
2. 写出使该用例通过的实现，运行定向测试。涉及外部依赖时，用项目已有的测试替身隔离调用。
3. 在测试通过后重构，重跑受影响的测试。重构已有功能时，先用测试固定调用方依赖的行为。
4. 交付时说明验证了哪个行为、运行了哪些测试以及结果。提交按 `AGENTS.md` 的授权范围执行。
